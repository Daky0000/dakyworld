Stage 9 · The retainer

Where a one-off project is meant to lead

Most clients arrive through a project — usually a website build — and the business only compounds if they move onto a care plan afterwards. This stage is the one that turns delivered work into recurring revenue, and it is the most automatic stage in the document.

9.1

The billing day comes round

Clock
Starts when
06:00 local time on the plan’s own billing day — before the working day starts, so an invoice is waiting rather than arriving mid-morning.
Does
Raises the invoice for the coming month and the closing month’s overage on the same document. A retainer is invoiced in advance because that is what a retainer is; hours cannot be, because how many were used is only known once the month has ended. So every cycle settles one cycle late.
Tools
carePlanBilling — scheduler, not an agent
Gate
Three defences against billing twice: (1) the next billing date is advanced before any invoice is written; (2) the period is derived from the calendar, not from when the job happened to run; (3) a duplicate period is a database constraint violation rather than a duplicate invoice.
Ends when
An invoice exists at DRAFT and the cycle is recorded as settled.
Stops and asks if
The plan is PAUSED or CHURNED — no invoice, and the history is kept. A restart after a long outage bills at most three missed months, never a year.
9.2

Keep the plan honest

Recurring Revenue Manager
Starts when
Monthly, after billing.
Does
Reconciles hours used against hours included, flags overage before the client sees it on an invoice, and reports what the retainer actually delivered that month.
Tools
careplan.readtime.readinvoice.draft
Gate
Level 3 to draft. Actual charges stay policy-gated regardless of level.
Ends when
The month is reconciled and the value report exists.
Stops and asks if
It would double-bill, or the usage figure cannot be traced to time entries. Never invent usage.
9.3

Book the review before it is late

Client Success Director
Starts when
A review falls due — the CARE_PLAN_REVIEW_DUE trigger.
Does
Offers slots and books the periodic review, with the month’s value report attached so the meeting starts from evidence rather than from “how’s it going”.
Tools
careplan.readcalendar.readcalendar.writeemail.draft
Gate
Level 3 to book and to send.
Ends when
The review is in the calendar.
Stops and asks if
It would promise an outcome the project data does not support.
9.4

Notice a client going quiet

Client Success Director
Starts when
Weekly health review.
Does
Watches for the four things that precede churn: silence, dissatisfaction, scope creep and payment friction. Scores each client and names the ones at risk with the reason.
Tools
client.readcareplan.readprojects.readanalytics.read
Gate
Read-only.
Ends when
Each client has status, value delivered, current risk, next action and owner.
Stops and asks if
Churn risk, a complaint, or a request that changes scope or price — all three escalate rather than being handled.
9.5

Reactivate the ones that went cold

Outbound Communications
Starts when
A lead that went LOST, or a client that churned, passes a set age.
Does
Runs the reactivation series — which carries an unsubscribe link, because this is a cold approach to somebody who has stopped hearing from you.
Tools
sequence.enrolsuppression.check
Gate
Level 3.
Ends when
They reply — which stops every sequence and returns them to Stage 4 — or the series ends.
Stops and asks if
They left unhappily. That is on the record, and it is a conversation you have, not one a sequence has.
Running alongside

The support loop

This one has no start and no end. It runs continuously against every client on a plan, and it is the only workflow in the document with a clock running against it that a client can see.

S.1

Triage

Support Desk
Starts when
A client makes contact — email, form or phone logged.
Does
Acknowledges, assesses severity against that client’s care plan, and either fixes what is routine — email, access, DNS, hosting — or routes it with everything the next person needs.
Tools
client.readcareplan.readprojects.readtasks.writeemail.draft
Gate
Drafting a reply is level 1; sending it is level 3.
Ends when
Resolved, or assigned to a named specialist with a due time.
Stops and asks if
A security incident, a data question, or anything touching money. Those go up immediately rather than being answered — the published commitment is a four-hour response on priority-one security incidents, and it is a commitment because a person meets it.
S.2

Escalate

Risk & QA Director
Starts when
Any agent, at any stage, hits a condition in Section 11.
Does
Reviews the proposed action against policy. If it exceeds policy, blocks it and explains why in one sentence, with the smallest compliant path forward.
Tools
company.auditsecurity.scanintegrations.readslack.send
Gate
May block anything at any level. Never weakens a control to make a task succeed.
Ends when
Allowed with a reason, or blocked with a reason and an alternative.
Stops and asks if
It is unsure. Uncertainty touching money, client data, a public claim or production always resolves conservatively.

The failure modes this document is designed around

Billing twice — three independent defences, Stage 9.1. Sending to somebody who opted out — suppression checked at the socket, not at compose, Stage 3.3. An agent looking equipped and not being — a grant naming a tool that does not exist is dropped on save and reported. Silent failure — every refusal is recorded with its reason, which is what makes “why did nothing happen last night” answerable at all.
