The one sentence that explains the whole design

An agent proposes; the gate decides; a person approves what leaves the building. Every agent seeds at autonomy level 1 with dry run switched on — it can research, read, reason, draft and prepare, and nothing it decides takes effect until somebody raises that level or approves that specific action. Everything else in these four books exists to make that promise true in code rather than in a prompt.

Where the books overlap, and which one wins

Books One and Two were built on 18 and 25 August 2026 and describe the system as it stood then; their generated tables — the roster, the catalogue, the clock, the writing jobs — were rebuilt for this volume and are current. Book Three is written against the code as of __BUILTDATE__ and is the authority wherever it contradicts an earlier page: it exists because the mechanisms it describes did not exist when the earlier prose was written. Book Four is generated in full and is the authority on any agent's actual instruction or any tool's actual arguments.
