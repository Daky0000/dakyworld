Stage 6 · Delivery

The specialists do the work

Every step above this one produces a decision, a status or a document. This is the stage where something is actually made — and it is the only stage where the agent doing the work is chosen by craft rather than by department.

6.0

Route the task to a craft

Delivery Director
Starts when
A task moves to TODO with no owner.
Does
Matches the task against the skills on each specialist — “Subtitles and burned-in captions”, “Local SEO and Google Business Profile” — and assigns it. Skills are written in a client’s words for exactly this reason.
Tools
agents.readtasks.writeprojects.read
Gate
Level 3 to assign unattended.
Ends when
The task has an owner and a due date.
Stops and asks if
No specialist’s skills cover it. That is a hiring signal, not an assignment problem — and hiring a specialist is one screen.

6.1 · The build lane — Web Developer, Automation Engineer, QA

6.1.a

Build the pages

Web Developer
Starts when
A build task is assigned.
Does
Produces a complete, self-contained page on the brand design system — real copy in Dakyworld’s voice, semantic markup, one h1, alt text, visible focus states, contrast that passes AA, and real breakpoints. Returns with it a list of what a developer must change before it ships.
Tools
web.pagegithub.readgithub.issuetasks.write
Gate
web.page writes nothing outward and runs at level 1. Opening an issue is outward: level 3.
Ends when
The page exists and the task moves to REVIEW.
Stops and asks if
The change touches production, a client’s DNS, or a live site’s availability. Nothing goes near production without a stated rollback.
6.1.b

Wire the systems together

Automation Engineer
Starts when
An automation task is assigned.
Does
Maps the current path step by step before proposing a new one, then builds it — saying which steps disappear and which merely move. Every integration names its failure mode and what happens to a record when it fires.
Tools
webhooks.readwebhook.dispatchintegrations.readgithub.read
Gate
Dispatching outward: level 3.
Ends when
The workflow runs and the manual steps it replaced are named.
Stops and asks if
It would write into a client’s system, move money, or send on a client’s behalf. Those are prepared and approved, never run unasked. A secret is never logged.
6.1.c

Try to break it

QA Tester
Starts when
A task reaches REVIEW.
Does
Tests against the acceptance criteria, then against what a real person would do instead. Checks TLS, mail authentication, forms, links and accessibility. Every defect carries steps, expected, actual and severity.
Tools
company.auditsecurity.scangithub.issuetasks.write
Gate
Level 3 to raise an issue.
Ends when
Every task is DONE or has a defect against it.
Stops and asks if
It has not actually exercised the work. It never signs off on inspection alone, and a blocker goes up the same day it is found.

6.2 · The studio lane — Design, Video, Ads, Copy, SEO

Four of the five studio tools produce a specification rather than a finished artefact. That is the honest boundary of what this system does alone — and it is also what a designer, an editor or a developer actually wants handed to them. The fifth, image.generate, makes a real picture, and can only do so through a connected MCP server.

SpecialistToolWhat comes back
Graphic Designerdesign.brief Objective, audience, reading hierarchy, the exact set-ready copy, the palette drawn from the brand system, real pixel dimensions per placement, and what would break the system on this piece.
Video Editorvideo.plan Structure with second counts that add up to the target, the shot list, the burned-in caption script, music direction, and the cut per platform with aspect and duration.
Ad Designerad.concept Genuinely different angles — not variants of one idea, which test nothing — each with hook, visual, primary text, headline and CTA; plus the platform specs, the test plan, and the claims that need checking first.
Copywritercontent.draft The copy, the audience, the proof behind every claim, and a separate list of anything unevidenced. Spends on Claude.
SEO Specialistcompany.audit The technical faults costing rankings, ranked by what they cost, each with its evidence and its fix. Fix what is broken before chasing what is missing.
Designer / Adsimage.generate An actual image, through whichever MCP server is connected. Spends — level 4. With none connected it refuses with a sentence saying what to connect.

Why image.generate names a capability rather than a provider

A specialist’s toolkit says “this one draws”. Which service draws is a connection you make on the Tools screen and can change without touching an agent, a seed or a deploy. That is the same reason the tool catalogue has two halves: what a tool does stays in code where it can be reviewed, and which servers are trusted and how far is configuration, because that is a permission and permissions are yours.

Stage 7 · Handover

Finishing properly

A project that is technically finished and not handed over is a project the client thinks is late. This stage is short on purpose.

7.1

Hand over the work

Client Communications
Starts when
Every milestone is complete and QA has signed off.
Does
Sends the handover: what was built, what changed for their business, what they need to do, and the files attached. Moves the project to DELIVERED.
Tools
email.draftemail.senddocument.renderprojects.read
Gate
Level 3.
Ends when
Project status is DELIVERED and the client has the deliverables.
Stops and asks if
It would expose internal notes, internal costs, credentials, or another client’s data. Never.
7.2

Ask for the thing you never ask for

Automatic
Starts when
The project reaches DELIVERED and a PROJECT_COMPLETED sequence is active.
Does
Runs the short series that asks for a testimonial and opens the care-plan conversation — the two things that are always meant to happen after a good delivery and almost never do.
Tools
sequence.enrol
Gate
Level 3.
Ends when
They reply, or the series ends.
Stops and asks if
The delivery went badly. A testimonial request after a difficult project is worse than silence — check the project’s own record first.
Stage 8 · Invoicing and collection

Getting paid

Not being paid is the failure everybody plans for. Being paid twice is the one that costs a client relationship, and three separate mechanisms exist to prevent it.

8.1

Raise the invoice

Finance Controller
Starts when
A milestone completes, a project is delivered, or a retainer period comes due.
Does
Drafts the invoice against the accepted proposal, takes the next number in sequence, and renders the PDF on the letterhead.
Tools
invoice.draftfinance.readdocument.render
Gate
A write; level 3 unattended. Every figure must trace to a source record — never a number the agent worked out.
Ends when
The invoice exists at DRAFT with a number, a due date and line items.
Stops and asks if
Any non-routine charge, refund or dispute; or any figure it cannot trace. Never charges without a validated billing rule.
8.2

Send it

You
Starts when
The draft exists.
Does
You send it. The PDF is rendered at send time, so a line item changed this morning is on the invoice that goes out this afternoon. A Stripe payment link is attached when Stripe is connected.
Tools
email.draftemail.senddocument.render
Gate
A person, always. Every invoice raised by the system is DRAFT, deliberately — a status that says “sent” with no email behind it is worse than one that waits.
Ends when
Status is SENT, then VIEWED when they open it.
Stops and asks if
Always.
8.3

Chase it

Automatic
Starts when
The due date passes and the invoice is not PAID. Status moves to OVERDUE.
Does
Starts the INVOICE_OVERDUE series — reminders that escalate in tone on a schedule rather than in somebody’s head.
Tools
sequence.enrolfinance.read
Gate
Level 3.
Ends when
Payment lands and the status moves to PAID, which stops the series.
Stops and asks if
The client has raised a dispute, or the amount is contested. A reminder sent into a dispute makes it worse.
8.4

Watch the money

Finance Controller
Starts when
Weekly, or on request.
Does
Reconciles invoice status against payment status and reports: cash position, days sales outstanding, MRR, what is owed and how late, unusual discounts, low-margin projects, and spend spikes.
Tools
finance.readanalytics.readcareplan.read
Gate
Read-only. Runs at any level.
Ends when
The report exists, with what needs a decision named.
Stops and asks if
Any figure it cannot trace to a record.
